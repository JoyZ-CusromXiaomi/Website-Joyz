Bagaimana cara membeli? +

Klik tombol “Beli via WhatsApp” pada produk. Pesan berisi nama produk, ID, dan harga akan terisi otomatis. Kirim, lalu admin akan memandu pembayaran dan pengiriman file.

Format file apa yang saya dapat? +

Setiap produk mencantumkan format dan spesifikasinya pada tag, misalnya Figma, PSD, PNG, atau AI. Detail lengkap ada di halaman “Detail”.

Bolehkah dipakai untuk proyek klien? +

Boleh. Aset dapat dipakai untuk keperluan komersial, tetapi tidak boleh dijual ulang atau dibagikan sebagai file mentah.

Apakah ada refund? +

Karena berupa produk digital, refund tidak tersedia kecuali file rusak atau tidak sesuai deskripsi. Hubungi admin dan kami bantu selesaikan.
